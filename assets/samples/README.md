# EPUB de démonstration

`vingt-mille-lieues-chapitre-1.epub` contient le premier chapitre de la première
partie de **Vingt mille lieues sous les mers**, de Jules Verne : **Un écueil
fuyant**. Le texte original est dans le domaine public.

Cet EPUB de test est fabriqué pour le projet à partir du texte du chapitre,
sans couverture, illustrations ou autres chapitres. Il contient les 28
paragraphes du récit ; la légende d’une illustration n’est pas reproduite.
Le récit commence par « L’année 1866… » et se termine par la demande de
débarrasser les mers du « formidable cétacé ».

Référence publique : [Jules Verne, édition Hetzel, 1870, chapitre I sur Wikisource](https://fr.wikisource.org/wiki/Vingt_mille_lieues_sous_les_mers/Partie_1/Chapitre_1).

L’installateur copie ce fichier dans `input/test` uniquement s’il n’y a pas
déjà de fichier de même nom. Les livres personnels de `input` ne sont pas
publiés dans le dépôt.
